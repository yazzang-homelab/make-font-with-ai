# 제작 목적 인터뷰 — 2단계의 첫 번째 게이트

레퍼런스를 고른 직후, 이미지에서 윤곽을 추출하기 전에 사용 목적을 확정한다.
레퍼런스는 스타일 후보이며, 목적과 충돌하면 사용자와 조정한 뒤 확정한다.

## 먼저 물을 질문
- 어디에 쓸 글꼴인가? 게임 제목 / 레트로 게임 대사 / UI / 자막 / 인쇄 / 본문 등.
- 실제 표시 크기는 무엇인가? `16x16 고정 셀`, `16px 정도`, `16x16처럼 보이는 스타일`은 서로 다르다.
- 어떤 엔진·프로그램에서 어떤 문자 범위를 사용할 것인가?

이미 답한 내용은 추출해 채운다. 모르는 항목은 쉬운 말로 확인하고, 기본값은 제안 후 승인받는다.

## 답변에 따라 달라지는 제작 사양

| 항목 | 16x16 레트로 대사체 예시 | 대형 붓글씨 제목체 예시 |
|---|---|---|
| 제작 단위 | 정수 픽셀 격자 | 벡터 윤곽·문맥형 |
| 기준 출력 | 네이티브 1배율 16x16 | 확정한 실제 제목 크기 |
| 중요한 제약 | 셀·베이스라인·고정폭·1픽셀 틈·판독성 | 붓의 압력·곡선·테이퍼·자모 배치 |
| 시각 비교 | 1배율 + 최근접 정수배 확대 | 원본 크기 + 필요한 축소 크기 |
| 산출물 확인 | 엔진이 쓰는 bitmap/atlas와 매핑 또는 검증된 TTF | TTF와 실제 렌더링 |
| 문장 검사 | 대사창 줄바꿈·행간·문장부호 | 제목·자간·크기별 밀도 |

이 표의 설정은 설명용 예시이며 모든 프로젝트에 자동 적용하는 값이 아니다.
문자 집합은 현대 한글 11172자, KS X 1001 한글 2350자, ASCII 또는 사용자 지정 집합 중 사용처에 맞춰 확정한다.
문자 집합과 파일 내부 인코딩/문자 순서는 다른 항목이다.

## 확인 요약의 예시

“레트로 RPG 대사용, 16x16 고정 셀, 단색 픽셀, 지정한 한글 집합과 영문·숫자·기호,
16px 1배율 및 최근접 2배율, 고정폭 16px, 행간과 베이스라인은 제안값으로 확인,
사용 엔진에 맞는 산출물과 TTF를 각각 검수.”

‘엔진에 맞는 산출물’, 문자 범위, 베이스라인처럼 중요한 값이 아직 미정이면 최종 승인으로 처리하지 않는다.
인터뷰 결과는 `design-brief.json`으로 저장하고, 사용자 확인 후에만 구현 단계로 이동한다.
승인 이후 핵심 값이 달라지면 승인과 관련 검수 결과를 무효화하고 다시 확인한다.

## 완료와 미완료를 구분할 것
이 문서는 스킬의 제작 사양과 검수 분기를 정의한다. 16x16 프로파일 설명이 있다는 사실만으로
bitmap exporter, 실제 게임 엔진 호환성 또는 3개 OS의 CI 실행이 완료되었다고 보고하지 않는다.
