# Purpose-driven production: implemented contract

Stage 2A is a mandatory purpose/use-case interview. Stage 2B is a confirmed, reference-bound production brief. The Python CLI enforces incomplete/stale brief rejection before candidate construction.
Pixel and vector use separate native-size and outline gates. Hybrid means two independently reviewed projects in v0.1. Build OS and target runtime are separate.
The CLI implements candidate writing, real proofs, explicit review and final TTF save/reopen, with PNG atlas export. Draft examples intentionally have no production approval. Current publication and CI status must be read from the actual repository and workflow results, never inferred from this document.
