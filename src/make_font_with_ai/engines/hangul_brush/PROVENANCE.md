# R36 reference engine

Derived from the author-requested BrushBalance R36 project. Its contour data are the project's own image-reference construction, not outlines extracted from a third-party commercial font.
The old glyph engine is retained without aesthetic claims or historical environment paths. The outer pipeline performs a new build and new checks. This is a specific heavy Korean brush family, NOT automatic style transfer to arbitrary references.
Generic new references use the vector/bitmap drawing workflow; adopting new pressure masters here requires a new candidate and review. Project license is PolyForm Noncommercial 1.0.0. No compiled fonts are distributed.
